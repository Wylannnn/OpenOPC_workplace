## 一、品牌视觉定位

### 风格关键词
**温暖 · 开胃 · 生活化 · 真实感 · 治愈系**

### 与姐妹项目（AI商业观察）的差异化
| 维度 | AI商业观察 | 电商带货（本项目） |
|------|-----------|-----------------|
| **风格** | 暗色科技美学 | 温暖生活美学 |
| **色调** | 太空黑+电光青 | 暖橙+米白+自然光 |
| **氛围** | 权威、科技、冷感 | 亲切、食欲、温暖 |
| **字体** | 无衬线超粗+负字距 | 圆润手写感+清晰标题 |
| **构图** | 瑞士网格+非对称 | 居中产品+场景化 |
| **情绪** | 专业数据感 | 生活方式感 |

## 四、构图规范

### 小红书（3:4 = 768×1024）
| 图片类型 | 构图要点 | 产品占比 | 文字占比 |
|---------|---------|---------|---------|
| **封面** | 产品居中/偏左，标题右上/左下 | 50-60% | 20-30% |
| **产品特写** | 微距拍摄感，细节清晰 | 80-90% | 5-10% |
| **场景图** | 生活场景（追剧/早餐/办公） | 40-50% | 10-15% |
| **细节图** | 局部特写（拉丝/夹心/材质） | 70-80% | 5-10% |
| **价格图** | 产品+价格标签+卖点 | 40-50% | 30-40% |

### 抖音（9:16 = 720×1280）
| 图片类型 | 构图要点 | 产品占比 | 文字占比 |
|---------|---------|---------|---------|
| **封面** | 产品居中，标题醒目 | 50-60% | 25-35% |
| **产品图** | 白底/场景，清晰展示 | 60-70% | 10-15% |
| **场景图** | 生活化场景，代入感 | 40-50% | 10-15% |

## 五、产品分类视觉策略

### 🍪 零食类（无骨鸡爪、紫米面包、手撕鸭脖）
- **色调**：暖色调（橙/黄/棕），激发食欲
- **光线**：自然侧光/窗光，温暖柔和
- **背景**：木纹桌面、编织餐垫、亚麻布
- **道具**：柠檬片、辣椒、薄荷叶、牛奶杯
- **情绪**：治愈、满足、分享的快乐
- **文字风格**：口语化、感叹号、emoji

### 🏠 日用百货类（便携榨汁杯、桌面收纳盒）
- **色调**：冷色调（白/蓝/绿），干净清爽
- **光线**：明亮均匀，产品细节清晰
- **背景**：纯白/浅灰背景，或简约生活场景
- **道具**：水果、化妆品、文具
- **情绪**：整洁、高效、品质生活
- **文字风格**：功能导向、数字量化、对比

## 六、图片生成策略

### 生成流程
1. **首轮生成**：每个产品生成封面+产品+场景+细节+价格（小红书6-9张）
2. **首轮生成**：每个产品生成封面+产品+场景（抖音3-5张）
3. **迭代优化**：根据生成效果调整prompt，至少2轮迭代
4. **最终输出**：统一命名，写入对应目录

### 命名规范
```
小红书：{产品名}-redbook-{类型}-v{版本}.png
  类型: cover(封面), product(产品), scene(场景), detail(细节), price(价格)

抖音：{产品名}-douyin-{类型}-v{版本}.png
  类型: cover(封面), product(产品), scene(场景)
```

## 七、质量检查清单

### 零食类
- [ ] 色调是否温暖、激发食欲？
- [ ] 产品是否清晰、占据画面主体？
- [ ] 光线是否自然柔和？
- [ ] 文字是否清晰可读？
- [ ] 场景是否有生活代入感？
- [ ] 是否避免过度修图（保持真实感）？

### 日用百货类
- [ ] 色调是否干净清爽？
- [ ] 产品细节是否清晰可见？
- [ ] 功能卖点是否一目了然？
- [ ] 背景是否简洁不杂乱？
- [ ] 是否有使用场景展示？
- [ ] 是否突出性价比/功能优势？
