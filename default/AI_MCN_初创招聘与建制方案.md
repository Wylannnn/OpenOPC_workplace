## 一、公司名称与注册方案

### 公司名称建议

| 类型 | 示例名称 | 说明 |
|------|---------|------|
| 科技感 | XX智媒科技有限公司 | 突出 AI 技术属性 |
| 营销感 | XX聚创营销传媒有限公司 | 行业通用，利于商务合作 |
| 品牌感 | XX星云文化传媒有限公司 | 适合达人孵化场景 |

> **建议**：公司名称中建议包含"科技"或"传媒"字样，以便后续申请高新企业或相关资质。

### 公司注册基础信息

| 项目 | 建议内容 |
|------|---------|
| 公司类型 | 有限责任公司（推荐） |
| 注册资本 | 50-100万元（认缴制，无需实缴） |
| 经营范围 | 互联网信息服务、文化娱乐经纪人服务、广告设计/制作/代理/发布、市场营销策划、数字内容制作、AI技术开发等 |
| 注册地 | 建议选在有税收优惠的孵化器或产业园区（如杭州/深圳/成都等） |
| 股东结构 | 创始人持股≥70%，预留10-15%期权池，其余给联合创始人 |

### 注册流程步骤

```
第1步：公司名称预核准（1-3个工作日）
    ↓
第2步：提交注册材料、领取营业执照（3-5个工作日）
    ↓
第3步：刻章备案（公章、财务章、法人章、发票章）（1个工作日）
    ↓
第4步：银行对公账户开户（3-7个工作日）
    ↓
第5步：税务登记与核定税种（3-5个工作日）
    ↓
第6步：社保/公积金开户（可后续办理）
    ↓
启动运营
```

## 二、岗位编制总览

初创阶段（1-10人）采用 **"1+3+1+1+1" 配置模式**：

```
创始人/CEO（1）
├── 内容与达人运营（2人）  ← 核心产出线：内容+达人孵化
├── 商务与增长（1人）     ← 核心变现线：商务+投放
├── AI技术/数据分析（1人） ← 技术赋能线：AI工具+数据
├── 财务/行政（1人兼职）   ← 后台支持线：财务+行政
└── AI员工（若干）        ← 数字生产力线
```

### 人员编制表

| 编号 | 岗位 | 人数 | 类型 | 月薪预估 | 年度成本 |
|------|------|------|------|---------|---------|
| 1 | CEO/创始人 | 1 | 全职 | — | 创始人自投入 |
| 2 | 内容运营专员 | 1 | 全职 | 8-15K | 12-18万 |
| 3 | 达人运营专员 | 1 | 全职 | 8-12K | 10-15万 |
| 4 | 商务拓展专员 | 1 | 全职 | 8-12K+提成 | 12-20万 |
| 5 | AI技术专员 | 1 | 全职 | 15-25K | 18-30万 |
| 6 | 财务/行政 | 1 | 兼职/外包 | 3-5K | 4-6万 |
| — | **AI员工（工具替代）** | 若干 | AI订阅 | 5-10K/月工具费 | 6-12万 |

> 年度人力总成本约 **62-101万**（含AI工具投入）

## 三、各岗位招聘画像与JD详解

### 岗位1：内容运营专员

**定位**：公司的内容发动机，同时负责内容生产和部分达人内容管理

**招聘画像**：

| 维度 | 要求 |
|------|------|
| 经验 | 1-3年新媒体/短视频内容经验，有成功案例优先 |
| 技能 | 熟练使用AI内容工具（ChatGPT/Claude/剪映/可灵AI/Midjourney），有视频拍摄剪辑能力 |
| 作品 | 需提供个人主导的短视频/图文作品集 |
| 特质 | 网感强，热点敏感度高，数据导向，能承受快节奏输出 |
| 加分 | 有MCN或达人内容运营经验、有爆款内容案例 |

**JD核心要点**：

```
职位：内容运营专员
汇报对象：CEO/创始人
薪资：8-15K/月 + 绩效奖金

职责：
1. 负责达人短视频/图文内容的选题策划、脚本撰写（AI辅助）
2. 使用AI工具进行文案生成、视频剪辑、封面设计
3. 追踪平台热点，制定内容日历，保证每周5-7条优质内容输出
4. 分析内容数据（播放量、完播率、互动率），持续优化内容策略
5. 管理3-5个达人账号的内容排期和发布计划
6. 探索AI生成视频/数字人内容的新型生产方式

必须会用的工具：
- AI写作：ChatGPT / Claude / 通义千问
- AI视频：剪映AI / 可灵AI / Runway
- AI设计：Canva AI / Midjourney / 稿定AI
- 数据分析：新榜 / 蝉妈妈 / 飞瓜数据
```

### 岗位2：达人运营专员

**定位**：公司的达人资产管理者，挖掘、签约、维护达人关系

**招聘画像**：

| 维度 | 要求 |
|------|------|
| 经验 | 1-2年达人运营/经纪人/主播招募经验 |
| 资源 | 有一定的达人/创作者人脉资源或挖掘渠道 |
| 技能 | 沟通谈判能力强，了解平台规则（抖音/小红书/视频号） |
| 特质 | 社交型人格，抗压能力强，结果导向 |
| 加分 | 自己做过内容账号（哪怕是小号）、有签约案例 |

**JD核心要点**：

```
职位：达人运营专员
汇报对象：CEO/创始人
薪资：8-12K/月 + 签约奖金 + 达人流水提成

职责：
1. 通过社交媒体、行业渠道挖掘潜力达人（素人/中腰部KOL）
2. 负责达人签约谈判、合同管理、关系维护
3. 为签约达人制定账号定位和成长路径规划
4. 协调内容团队为达人提供内容支持
5. 跟踪达人账号数据，识别高潜力达人并重点孵化
6. 建立达人资源库，分级管理达人资源

关键指标：
- 月签约达人数量（目标：月签2-5人）
- 达人月均播放量/粉丝增长
- 达人流水贡献
```

### 岗位3：商务拓展专员

**定位**：公司的变现引擎，负责开拓品牌客户和广告收入

**招聘画像**：

| 维度 | 要求 |
|------|------|
| 经验 | 1-3年广告/商务/销售经验，有品牌客户资源优先 |
| 技能 | 出色的商务谈判能力和提案能力 |
| 资源 | 有品牌方/广告公司/PR公司对接资源 |
| 特质 | 自驱力强，结果导向，有一定抗压能力 |
| 加分 | 了解MCN广告报价体系、有成交案例 |

**JD核心要点**：

```
职位：商务拓展专员
汇报对象：CEO/创始人
薪资：8-12K/月 + 高额提成（流水10-20%）

职责：
1. 开拓品牌客户资源，建立商务合作渠道
2. 制定达人广告报价体系和合作方案
3. 对接广告投放需求，协调达人排期和执行
4. 跟踪广告ROI，维护客户关系，提升复投率
5. 探索AI智能接单/匹配系统的使用
6. 参与品牌营销方案策划

关键指标：
- 月广告收入（目标：3个月后月入5-10万）
- 客户数增长和复投率
- 达人商单匹配效率
```

### 岗位4：AI技术专员

**定位**：公司的技术核心，搭建AI工具链并赋能全员

**招聘画像**：

| 维度 | 要求 |
|------|------|
| 经验 | 1-3年AI应用/全栈开发经验 |
| 技能 | Python、API调用、大模型应用（GPT API/开源模型）、数据分析 |
| 作品 | 有AI工具搭建或数据可视化项目经验 |
| 特质 | 学习能力强，能把技术转化为业务价值 |
| 加分 | 了解数字人/视频生成/AI语音合成等技术、有MCN/营销领域经验 |

**JD核心要点**：

```
职位：AI技术专员 / AI应用工程师
汇报对象：CEO/创始人
薪资：15-25K/月 + 期权

职责：
1. 搭建公司AI工具链：文案生成、视频处理、数据分析自动化
2. 配置和维护AI数字人/虚拟主播系统（如有需要）
3. 开发内部数据看板：达人表现、内容效果、收入追踪
4. 部署AI客服/智能接单系统，提升商务效率
5. 为团队成员提供AI工具培训和日常技术支持
6. 探索新的AI工具，持续提升公司内容生产效率

必须掌握的技能：
- Python（Flask/FastAPI）、SQL
- 大模型API调用（OpenAI / 通义千问 / 文心一言）
- 数据可视化（Tableau / Metabase / Grafana）
- 了解视频处理（FFmpeg / OpenCV）

加分技能：
- ComfyUI / Stable Diffusion
- 数字人技术（HeyGen / 硅基智能 / D-ID）
- 爬虫/数据采集
```

## 四、AI员工配置方案

初创阶段，用 **AI工具/系统** 补齐招聘缺口，以下配置可以实现"1个AI员工"干传统2-3人的活。

### AI员工清单

| AI"员工"名称 | 替代岗位 | 推荐工具 | 月费/成本 | 职责 |
|-------------|---------|---------|----------|------|
| **AI内容助手** | 编导助理 | ChatGPT Plus + 剪映AI + 可灵AI | ~150元 | 脚本生成、视频剪辑辅助、封面设计 |
| **AI数据分析师** | 数据分析员 | 百度统计 + 新榜数据API + AI报表 | ~200元 | 内容数据追踪、达人表现分析、自动周报 |
| **AI投放机器人** | 投放优化师 | 巨量千川AI + 腾讯广告RTA | 按消耗 | 自动化投放、智能出价、ROI优化 |
| **AI客服/商务助理** | 商务助理 | 智能客服API + 飞书AI机器人 | ~100元 | 客户问答、商单匹配、合同模板生成 |
| **AI设计助手** | 初级设计师 | Midjourney + Canva AI + 稿定AI | ~200元 | 封面设计、海报制作、品牌视觉素材 |
| **AI数字人主播**（可选） | 主播 | HeyGen / 硅基智能 / 腾讯智影 | 500-2000元 | 24小时直播、产品讲解、视频口播 |
| **AI运营助手** | 社群运营 | 飞书/钉钉 + 自动化脚本 | ~50元 | 定时发布、自动回复、数据采集 |

### AI工具总月度预算

| 类别 | 预估月费 |
|------|---------|
| AI内容生产工具 | 500-1,000元 |
| AI数据分析工具 | 200-500元 |
| AI投放工具 | 按消耗（约2,000-5,000元初期测试） |
| AI数字人（如选用） | 500-2,000元 |
| 协作与管理工具 | 300-500元 |
| **合计** | **约 3,500-9,000元/月** |

### AI员工效能评估

| 对比项 | 传统模式 | 配置AI员工后 |
|--------|---------|------------|
| 日产出内容量 | 3-5条/人/天 | 8-15条/人/天（AI辅助） |
| 数据分析效率 | 周报需半日 | 实时自动生成 |
| 投放优化 | 人工盯盘调整 | AI自动优化+预测 |
| 设计产出 | 1套图需1-2天 | 批量生成+AI调整 |
| 达人匹配 | 手动筛选 | AI推荐+匹配排序 |
