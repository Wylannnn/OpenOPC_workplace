## 使用说明

本清单用于 **生成后质量验收**，覆盖品牌资产图片的六大检查维度。每项检查通过后打勾 ✅，未通过 ❌ 需记录问题并迭代修复。

**检查流程**：
1. 生成图片 → 2. 逐项检查 → 3. 记录问题 → 4. 迭代修复 → 5. 重新检查

### 亮度验证方法

```
亮度验证步骤：
1. 在 Photoshop/任何图片编辑软件中打开图片
2. 查看直方图（Histogram）
3. 确认峰值集中在 0-50 亮度值范围
4. 在图片上叠加 16px 白色文字（#F0F0FF）
5. 确认文字在所有区域清晰可读
6. 如有亮度过高区域 → 标记并记录
```
