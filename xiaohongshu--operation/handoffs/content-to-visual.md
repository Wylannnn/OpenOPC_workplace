# 内容策划 → 视觉设计 交接文档

## 交接背景
内容策划已完成《小红书AI内容账号竞品与受众分析报告》，确定了"AI商业观察"账号的差异化定位。现需视觉设计师基于此定位，设计一套完整的《视觉风格指南》。

## 账号定位摘要
- **账号名称**：AI商业观察
- **核心定位**：「用AI视角看懂商业世界」
- **目标受众**：职场白领（45%）+ 创业者/管理者（45%）+ 学生/其他（10%）
- **内容调性关键词**：专业不枯燥、易懂有价值、数据支撑、商业洞察
- **内容四大支柱**：
  1. 🏗️ AI商业案例（35%）
  2. 🛠️ AI效率方案（25%）
  3. 📊 行业趋势（25%）
  4. ⚠️ 避坑/洞察（15%）

## 视觉设计需求清单

### 1️⃣ 封面图模板（需设计3-4套）
- 对应四大内容支柱的差异化封面模板
- 尺寸：小红书图文封面标准（3:4比例，建议1242×1660px）
- 要求：重点突出标题文字，能快速传达内容价值

### 2️⃣ 内页图风格统一规范
- 信息图/数据图风格
- 截图+标注的处理方式
- 图文混排的版式规范

### 3️⃣ 配色方案
- 主色/辅色/强调色
- 考虑与"AI商业"调性匹配（建议科技蓝、商务灰、活力橙等）
- 需注明色号（HEX/RGB）

### 4️⃣ 字体选择
- 标题字体（建议1-2款）
- 正文字体（建议1款）
- 数字/数据字体

### 5️⃣ 品牌元素
- 账号头像建议方向
- 水印/版权标识方案
- 统一图标风格

## 需要Owner审批的节点
《视觉风格指南》最终稿需提交Owner审批通过后方可定稿。

## 参考竞品视觉风格
- @AI效率实验室：高饱和度橙蓝系，大字标题+数字强调
- @未来工作流：简约白底+莫兰迪色系，Before/After对比图
- @AI情报站：资讯卡片风格，emoji+关键词组合封面

**我们的差异化方向**：专业但不沉闷，数据可视化强，有科技感但不过度花哨

## 交接时间线
1. 视觉设计师收到需求后开始设计初稿
2. 初稿完成后 → 内容策划初审
3. 初审通过 → 提交Owner终审
4. 审批通过 → 视觉风格指南定稿 → 启动内容日历与物料生产
